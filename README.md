1. having fun with vibe coding ([oh-my-opencode](https://github.com/code-yeongyu/oh-my-opencode))
2. add a TUI optimized for modern terminal to make ckb-cli looks cooler

## Features

ZERO additional features compared to the original version, only looks prettier.

All features in the TUI should be self-explanatory; use [TAB] for auto-completion.

## Build this project

```
make prod
```

## Usage

1. make sure a ckb node is running;
2. run `ckb-cli`, or `ckb-cli -h` to learn how to use.
